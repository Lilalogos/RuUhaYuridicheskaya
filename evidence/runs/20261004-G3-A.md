# Прогон 2026-10-04 — сценарий G3 — фаза A (СТОП A.5)

Запуск: «3» — закрыть G2 и перейти к следующему сценарию; взят G3 (скрытая полная стоимость).

## 1. Доступ
- br.fas.gov.ru — curl 200 (карточки документов читаются; список поиска рендерится скриптом — поиск через Chrome, основной поиск type=2 = документы).
- Вложения документов /media/document_files/… — скачиваются curl.

3. br.fas.gov.ru «сервисный сбор» (type=2) → 69 документов, на первой странице — закупки/тарифы (не по теме).
4. br.fas.gov.ru «реклама стоимость без учета сборов» (type=2) → 119; Челябинское УФАС: дело 5-2015 («Победа», «Летим в Москву за 999 рублей»), постановления 78-14.3 ч.1/2015 и 57-14.3ч.1/15 по тому же факту.
5. br.fas.gov.ru: «интернет-сайте стоимость без учета сбора», «окончательная стоимость сервисный сбор», «сервисного сбора реклама», «на сайте цена указана без учета», «итоговой стоимости заказа» → Московское УФАС 077/05/5-2202/2019 (ООО «КС», билеты «от 1500 руб.»); Московское областное УФАС 050/05/5-2/2025 (Яндекс Go, промокод) — прочитано, не G3 (неприменённый промокод), папка удалена → Отложено.
6. WebSearch: `УФАС признало рекламу ненадлежащей цена на сайте без сервисного сбора билеты …` → наводка Пермское УФАС (avperm.ru).
7. WebSearch: `Роспотребнадзор суд сайт цена в каталоге отличалась от цены в корзине …` → практика ВС о цене на сайте как оферте (не G3 по сути) — не взято.
8. WebSearch: `Роспотребнадзор штраф 14.8 сервисный сбор билеты сайт …` → kubnews (обзор без дел).
