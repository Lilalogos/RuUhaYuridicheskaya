# Наводка: Wildberries, списания с карт, удалённых из личного кабинета (G4)
- Что: Подольский городской суд (Московская обл.) по иску Управления Роспотребнадзора по Тульской области признал противоправными действия ООО «Вайлдберриз» и обязал прекратить списание за товары по платёжным данным карт, удалённых из личного кабинета (по пересказу WebFetch). Номер дела не указан.
