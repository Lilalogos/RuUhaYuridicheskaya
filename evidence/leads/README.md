# evidence/leads — наводки

Наводка — указание, где искать первичку (акт суда, решение УФАС, постановление Роспотребнадзора). Наводка никогда не становится источником поля реестра (evidence/CLAUDE.md §0.2).

Два вида карточек:

- **Ручные** — `<ГГГГММДД>-<домен>.md`, написаны по итогам прогонов (журналы в `evidence/runs/`).
- **Сгенерированные из таблицы практики** — `<ГГГГММДД>-<домен>-P-NNN.md`, по одной на строку `evidence/practice/cases.tsv` (P-001…P-190); пересоздаются командой `python3 -B scripts/build_practice_leads.py --clean`. Руками их не править: правки — в таблицу или в ручную карточку с пометкой `P-NNN` в тексте (тогда генератор эту строку пропускает). Дата в имени — дата акта по таблице, если она полная; иначе `00000000`.

Папки: `G1`–`G8` — сценарии сбора (§1 регламента); `content` — контент, символика, статусы, модерация; `consent` — согласия и формы ПДн; `security` — защита данных и утечки; `platform` — ответственность площадок; `finance`, `ip`, `hr`, `gov`, `antitrust` — разделы таблицы вне охвата скрин-чекера (наводки сохранены для полноты).
