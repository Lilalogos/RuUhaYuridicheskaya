# Наводка: «Нордстар», обязательная «услуга по подбору провозной платы» (G2)
- Что: новость Управления Роспотребнадзора по Красноярскому краю «О незаконном взимании денег с пассажиров»: при покупке на сайте авиакомпании оплачивалась «услуга по подбору провозной платы (оформлению провозной емкости)» 550 руб. за сегмент, «Без оплаты указанной услуги приобретение билета было невозможным» (по тексту новости).
