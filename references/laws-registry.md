Источник всех записей — обзорный PDF «Правовая база РФ для проектирования интерфейсов» (капсула `src-0116437c998bcd82`, редакция 2026-09-29) плюс точечная сверка с pravo.gov.ru (отражена в `verified_as_of` и `citation`). Это вторичный источник: `availability: partial` у каждой нормы, перед выпуском сверять редакцию по КонсультантПлюс/Гарант/pravo.gov.ru. Суммы штрафов в базе не хранятся намеренно — только статьи.

Обозначения: **Маршруты** — id из `jurisdiction_routes.yml`, через которые норма достигает отчёта; **Паттерны** — id детекторов из `patterns.yml` с `maps_to_norms`; **Компаньон** — процедурный состав, который может сопровождать находку, но никогда не является её первичной нормой; «проверить» — метка самого обзора.
