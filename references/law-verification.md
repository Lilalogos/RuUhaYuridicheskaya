# Сверка норм с текстами законов (прогон «сбор пробелов», 2026-10-04)

Источник сверки — сохранённые страницы КонсультантПлюс с текстовым слоем в [`evidence/law/`](../evidence/law/INDEX.md) (slug → папка с `source.pdf`, `source.url.txt`, `source.sha256`, `meta.yml`). Официальный портал publication.pravo.gov.ru с этой машины недоступен (соединение не устанавливается), поэтому availability норм остаётся `partial`/`full` по решению куратора: КонсультантПлюс — тот справочник, который сам обзорный PDF называет местом сверки. Все реквизиты ниже — дословно из текстов; номера строк/страниц — по `source.pdf` конкретной папки.

Суммы штрафов в `norms.yml` по-прежнему не хранятся (политика обзора: «меняются почти ежегодно»). Здесь они приведены с датой редакции — для `Missing Context`/комментариев, не для строки «Monetary exposure».

## 3. Что осталось непроверенным или спорным

- **Дата вступления в силу 199-ФЗ (КоАП 13.55/13.56):** в сохранённом корне документа заключительная статья не читается (страница обрывается на перечне источников опубликования). Нужна постатейная страница «Статья 2» 199-ФЗ.
- **Дата вступления 561-ФЗ** (09.01.2026) — по новости КонсультантПлюс, в сохранённом тексте закона не найдена.
- **Дата действия ч. 2.1 ст. 14.8 (505-ФЗ)** — 30.10.2023 по новости КонсультантПлюс; в тексте закона — «вступает в силу со дня официального опубликования» (проверить по странице).
- **ФАП-82 п. 6, 13, 30** — сохранены оглавление и выбранные разделы; дословный текст пунктов перед цитированием сверять в разделах «Бронирование», «Оплата».
- **ПП 2463** — сохранён корень + разделы по фильтру; п. 18 (дистанционная продажа) — проверить в сохранённых разделах.
- **Официальные тексты (publication.pravo.gov.ru)** — недоступны с этой машины: `availability: full` у новых норм означает «текст статьи приложен из КонсультантПлюс», а не официальное опубликование.
- **Политика сумм штрафов** — база хранит статьи, не суммы (решение Миши/Виталия по обзору). Теперь суммы подтверждены текстами с датой редакции; решение, вносить ли вилки в `penalty_basis`, — за владельцами KB.

## 4. Как обновлять

1. Новый акт/статья → строка в `evidence/law/SOURCES.tsv` (slug, URL КонсультантПлюс, название); для корней амендмент-законов добавить slug в `EXPAND` в `scripts/fetch_laws.py`.
2. `python3 -B scripts/fetch_laws.py [slug…]` → PDF + meta + `INDEX.md`.
3. Сверка → правка `scripts/patch_norms_2026-10-04.py` (или новый patch-скрипт) → `python3 -B scripts/refresh_release.py` → `cd applaw && python3 -B scripts/validate_release.py --kb .`.
