# AppLaw-RU — чекер тёмных паттернов по российскому праву

Форк AppLaw, в котором база знаний держит **только российские законы и акты**.
Основатель присылает скриншоты чекаута/подписки, совет ИИ-агентов проверяет их
против зарегистрированных норм РФ и возвращает один вердикт: **pass**,
**issues** или **high risk** — с находками, привязанными к конкретной статье,
и блоками ответственности.

## Покрытие базы (v0.5.0-ru, сверка 2026-10-01)

| Слой | Состав |
|---|---|
| Материальные нормы — чекаут | ЗоЗПП ст. 8–10; ст. 16 (ред. 135-ФЗ + 69-ФЗ, возврат в 3 дня — п. 3.1); ст. 16.1 (ФЗ № 376-ФЗ, с 01.03.2026); ст. 32 + ГК 782; 38-ФЗ ст. 5 ч. 3 и 7; 289-ФЗ (ждёт P-04) |
| Материальные нормы — контент (волны 1–2) | госсимволы (ФКЗ 1/2/3-ФКЗ), символы Победы, экстремистская символика (80-ФЗ/114-ФЗ), активы и упоминания запрещённых организаций (перечни; решение ВС 30.11.2023), карты 89 субъектов, маркировка иноагентов (255-ФЗ), язык интерфейса (53/168-ФЗ), возрастной знак (436-ФЗ ст. 12); VPN-промо (149-ФЗ ст. 15.8), наркосимволика (6.13-практика), религиозные символы в промо (38-ФЗ 5 ч. 6), нежелательные организации (272-ФЗ), обязанности соцсетей (149-ФЗ 10.6), барьеры 18+ (436-ФЗ ст. 14), выходные данные СМИ (ст. 27) — см. docs/ru-content-domain.md |
| Процедурные компаньоны | КоАП 14.8, 14.3, 17.10, 20.3, 20.29, 20.33, 6.21, 6.13, 6.17, 5.26, 19.34.1, 13.22 (никогда не первичная норма находки) |
| Маршруты / факт-гейты | 56 маршрутов · 48 гейтов |
| Паттерны | 113; 7 — осознанно без маппинга с причинами |
| Источник | капсула `src-0116437c998bcd82`: 43 постраничных экстракта обзорного PDF, ~80 дословных пинов + официальная карточка ЗоЗПП на pravo.gov.ru; полная карта покрытия — docs/ru-coverage-map.md |
| Решения (outcomes) | реестр пуст по источникам — строка Observed benchmark всегда `None identified.` до приложения решений |

Суммы штрафов в базе **не хранятся** намеренно: обзор фиксирует статью, не
число («суммы меняются почти ежегодно»).

## Проверки

```bash
# вся релизная валидация базы (15 проверок; то же делает CI)
cd kb/applaw && python3 -B scripts/validate_release.py --kb .

# инвариант достижимости: каждая материальная норма доходит до отчёта
# или имеет записанную причину в docs/unmapped-norms.md
python3 scripts/check-norm-reachability.py
```

Текущее состояние: **PASS 15/15**. Флаг `-B` обязателен — случайный
`__pycache__` ломает подсчёт файлов релиз-профиля.

Приложение:

```bash
npm install
npm run dev        # http://localhost:3000 (офлайн-режим: PGlite + диск)
npm run lint && npm run typecheck && npm run build
```

Правки .ts в форке — строковые (копирайт, стаб, метки рынков);
`npm run build` после клонирования прогоните у себя.

## Правила форка

Логика валидаторов не ослабляется: юрисдикционные константы портированы на RU
той же строгости (леак-детектор внутренних id расширен на `ru-`; упоминание
российских властей без RU в преамбуле отчёта — reject). Защитные маркеры
FTC/CMA/CNIL в `validate_report.py` оставлены сознательно как негативные
тесты — подробности в [docs/ru-purge-report.md](ru-purge-report.md).
