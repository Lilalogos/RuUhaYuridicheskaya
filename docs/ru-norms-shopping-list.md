## 2. Позиции «(проверить)» из самого PDF, блокирующие поля

- ~~Срок возврата навязанной услуги~~ — **закрыто 2026-09-30**: п. 3.1 ст. 16 (ФЗ от 07.04.2025 № 69-ФЗ, с 01.09.2025) — «в течение трёх дней со дня предъявления требования»; внесено в ru-zozpp-16. Добрать карточку 69-ФЗ на publication.pravo.gov.ru.
- Пороги обязательного приёма «Мир» по ст. 16.1 — «сверить» (стр. 26).
- Штрафы платформ по 289-ФЗ — «отдельный закон 2026 г. (проверить)» (стр. 28).
- КоАП 13.55/13.56 — «дата начала действия — проверить» (стр. 64) → effective-date для предлагаемых паттернов.
- КоАП 6.21 по частям; Приказ Минкомсвязи № 161; «Честный знак»-акты; Госключ-постановление; антифрод-закон «41-ФЗ, номер — проверить»; закон об ИИ «подписание и номер — проверить» — фиксируются как условные, в чекаут-ядро не входят.

## 3. Практика для enforcement_outcomes (сейчас реестр RU пуст)

PDF даёт практику только россыпью («практика штрафов», «практика ФАС», «Право.ру: итоги 2025») без реквизитов дел → `eligible_outcome_ids` у всех RU-норм пусты, наблюдаемый ориентир в отчётах честно «нет данных». Нужны приложенными файлами:
- постановления/решения Роспотребнадзора и судов по ст. 14.8 КоАП о навязывании допуслуг и подписках (даты, номера, суммы, стадия);
- решения ФАС по 38-ФЗ ст. 5 ч. 3 (таймеры, «№ 1», мелкий шрифт) — PDF упоминает «практика ФАС» без дел;
- обзоры Право.ру «итоги 2025» (PDF ссылается, файл не приложен).

## 4. Отсутствует в PDF полностью (нужно для честных полей всех RU-норм)

- Исковая давность и подсудность потребительских требований; порядок обжалования предписаний → сейчас «Не установлено по приложенным источникам».
- Коллективные иски (групповые требования потребителей) → то же.
- Потребительский штраф/неустойка (в PDF отсутствуют как категория) → любые упоминания запрещены до приложения источника.
- Разъяснения Пленума ВС РФ по ЗоЗПП → усилили бы limitations, без них не ссылаемся.

## 5. Организационное

- Канонический URL хранения самого обзора (внутренняя вики/Drive) — чтобы заменить временный `official_url` капсулы (см. вопрос № 1 в отчёте).
- 3–5 русскоязычных скриншотов для gold-фикстур и 2–3 «чистых» экрана для clean-бенчмарков — присылает оператор (этап 7.3 промпта).

## 6. Карточки pravo.gov.ru — добрать точные URL (решение оператора № 1)

ЗоЗПП закрыт консолидированной ips-карточкой (nd=102014512) в source_url и liability_source_urls четырёх норм. Остались точные карточки официального опубликования: ФЗ № 69-ФЗ от 07.04.2025; ФЗ № 135-ФЗ от 01.05.2022; ФЗ № 376-ФЗ от 15.10.2025; ФЗ № 289-ФЗ (и № 290-ФЗ) от 31.07.2025; ips-карточка КоАП РФ (195-ФЗ). До их приложения `ru-koap-14-8` и `ru-289fz-platform` несут портал publication.pravo.gov.ru с оговоркой в limitations.
