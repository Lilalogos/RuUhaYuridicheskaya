# Что прислать, чтобы улучшить скилл

Каждая позиция ниже закрывает конкретные пустые поля базы. Правило приёмки
одно — cite-or-abstain: пока материал не приложен файлом, соответствующее поле
остаётся условным или пустым; ничего не дописывается по памяти.

## P0 — разблокирует измеримость и 289-ФЗ

**1. Скриншоты gold (5–6 кейсов) и clean (3 экрана).**
Полная спецификация — [docs/ru-gold-clean-spec.md](ru-gold-clean-spec.md).
Сценарии: G1 предвыбранная платная допуслуга · G2 отказ блокирует покупку ·
G3 скрытая полная стоимость · G4 подписка без электронного отказа /
списания после удаления карты · G5 отмена услуги только по телефону ·
G6 таймер + «осталось 2 шт.» + «№ 1» без источника; clean — те же сценарии,
сделанные честно. Технически: русский интерфейс; лучше «Печать → PDF»
(нужен текстовый слой — капсула принимает только PDF с sha256 и страницами);
серии кадров по порядку; ничего юридически значимого не замазывать; к каждому
кейсу — манифест по шаблону из §2 спецификации (ожидаемые паттерны, факты,
маршрут, класс). Даты: кейс по ст. 16.1 — после 01.03.2026, по 289-ФЗ — после
01.10.2026.
*Закрывает:* `eval/gold.json`, `benchmarks/clean/`, первые метрики качества.

**2. Решения по предложениям паттернов P-01…P-05.**
По каждому пункту [docs/ru-pattern-proposals.md](ru-pattern-proposals.md)
одно слово: «принять» / «отклонить (почему)» / «доработать (что)».
«Принять» = мини-батч: паттерн + гейты + маршрут (+ процедурный спутник).
**P-04 `marketplace-sort-override` разблокирует норму `ru-289fz-platform`** —
сейчас она единственная в allowlist недостижимых
([docs/unmapped-norms.md](unmapped-norms.md)).
*Закрывает:* достижимость 289-ФЗ; паттерны под ГК 426, 149-ФЗ ст. 10 и
10.2-2, cookie-риск.

## Как присылать

Прямо в чат (PDF кейсами или ZIP с PNG + манифесты) либо PR в этот репозиторий.
Именование: `ru-gold-<case>/<nn>-<screen>.png`, официальные тексты —
`law/<акт>-<дата-редакции>.pdf`, решения — `outcomes/<орган>-<номер>-<год>.pdf`.
После приёмки каждой позиции прогоняется полный релизный контур
(`validate_release.py`, 15 проверок) и инвариант достижимости.
