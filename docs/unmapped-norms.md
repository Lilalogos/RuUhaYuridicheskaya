# Нормы без маршрута: allowlist с причинами (RU-форк)

`scripts/check-norm-reachability.py` требует, чтобы каждая материальная норма
достигала отчёта через паттерн или маршрут — либо имела запись здесь, ниже
горизонтальной черты, в формате `- \`id\`: причина`.

---

- `ru-289fz-platform`: заведена 2026-10-01 по прямому указанию оператора до принятия паттерна P-04 «marketplace-sort-override»; закон в силе с 01.10.2026, членство платформы в реестре ПЦП с экрана не видно — см. docs/ru-pattern-proposals.md и docs/ru-unmapped-patterns.md.
- `ru-zozpp-16-1-digital-ruble`: заведена 2026-10-04 по тексту ст. 16.1 ЗоЗПП (248-ФЗ): обязанность крупных продавцов принимать цифровые рубли с 01.09.2026; паттерна «отсутствует обязательный способ оплаты» в базе нет, пороги выручки с экрана не видны — ждёт паттерн и effective-date-гейт (см. references/gaps.md).
- `ru-zozpp-16-1-installment-price`: заведена 2026-10-04 по тексту ст. 16.1 п. 4.1 ЗоЗПП (284-ФЗ): запрет разных цен по способу оплаты/рассрочке; паттерна «разная цена по способу оплаты» в базе нет — ждёт паттерн (см. references/gaps.md).
