# Паттерны без RU-нормы в приложенных источниках (срез после батча 1)

Формулировка причины — по протоколу промпта: «в приложенных актах прямой обязанности нет; наблюдение уходит в Missing Context без юридического вывода». Инвариант достижимости выполняется второй стороной: каждый паттерн ниже имеет записанную причину.

| Паттерн | Причина отсутствия маппинга (по PDF) | Поведение чекера |
|---|---|---|
| single-option-cta | Единственная CTA сама по себе не «недопустимое условие» ст. 16 и не искажение информации ст. 10; PDF квалифицирует навязывание только через предвыбор платного, блокировку отказа или скрытие цены (стр. 26, 30). | Наблюдение фиксируется; юрвывод — только если экран одновременно активирует ценовой или консент-маршрут. |
| commitment-escalation | Давление вовлечённостью без искажения цены/условий PDF не квалифицирует; ближайшие нормы (38-ФЗ 5 ч. 3) требуют недостоверного утверждения, а не механики. | Missing Context без юридического вывода. |
| task-sunk-cost | То же: затраченное усилие не создаёт обязанности по приложенным актам; цена после усилия закрывается ст. 10 через `personalization-lure`/`delayed-price-disclosure`. | Missing Context; при скрытой цене — маршрут ru-total-price-disclosure. |
| anxiety-trigger | Эмоциональное давление вне детской аудитории PDF не нормирует (38-ФЗ ст. 6 — только детям, «без таймеров и давления дефицитом» помечено как рекомендация, стр. 35). | Missing Context; для детской аудитории — кандидат б3 усл. |
| motivation-loop | Геймификация мотивации не покрыта приложенными актами; 38-ФЗ 9 касается только объявленных стимулирующих акций. | Missing Context. |
| shame-based-pressure | Стыдящие формулировки PDF не нормирует; 38-ФЗ 5 ч. 6 (оскорбительные образы) — про рекламу и образы, натяжка без визуального рекламного контекста. | Missing Context; при рекламном креативе — б2 усл. через 38-5-6. |
| repeated-prompt | Повторные предложения без блокировки отказа не образуют обусловливания ст. 16 («Отказ от доп. услуги блокирует…» — стр. 30 требует именно блокировку). | Missing Context; при блокировке — маршрут ru-conditioned-purchase. |

Ревизия этого списка — после батчей 2–3 (38-ФЗ ст. 5/9 закроет часть pressure/social-proof контекстов, список пересчитывается).
